# Test Authoring

仅记录前沿模型在复杂异步与回归测试中易踩的非显然边界；框架、命令与运行时取证见宿主仓库验证文档。

## 异步完成与隔离

- **等最终承诺效果**：先注册观察再触发操作，并关联目标请求/实例；入队、落库或首个 observer 回调只证明中间阶段，不代表操作完成。
- **确定性等待与退出清理**：等待 helper 区分成功/失败/取消/超时（超时带阶段、耗时与最后读数）；多阶段等待显式传递预算；每条退出路径（成功、断言失败、抛错）释放 timer、observer、listener、帧回调并恢复共享状态，不依赖进程退出清理。
- **负向断言边界**：先证明触发进入目标路径（取消/卸载用例须先证明在途工作已启动），再断言未发生或已中止；固定 microtask 次数、若干帧或安静时间只证明所观察区间，不证明在途工作已完成。

## 保护力与防假绿

- **变异自证**：判断测试有效或精简/删除既有用例前做一次反向变异——改坏被测行为时测试必红、恢复必绿；拔掉或短路某项检查后仍全绿只说明缺少承重用例，不足以证明可删。
- **避开同义反复与失真 mock**：期望值取独立来源（fixture、手工常量、协议样例），不复用被测实现表达式；mock 须对齐真实依赖的异步阶段、超时/取消与结构化错误语义，需要验证依赖交互本身时改用真实依赖或契约测试。
- **证据核实**：收窄测试范围后用输出中的用例/文件计数证明收窄生效；改动报错文案后对比总数并同时检索新旧措辞；两方证据数字对不上时标记「未查清」继续查，不挑一支信。
