# UI 与样式约束

- **Tailwind 间距**：padding、margin、gap、space 使用 Tailwind spacing 纯数字刻度（如 `p-3`、`gap-1.5`、`-mr-2`），不写 `p-[12px]`；仅刻度外数值（如 `5px`、`7px`）用 `px` 任意值。
- **单位**：禁止手写 `rem`；CSS 长度优先 `px`，无单位属性（`line-height`、`z-index`、`flex`、`opacity`）写纯数字。
- **同心圆角**：同心嵌套表面遵循 `外圆角 = 内圆角 + 间距`（不同单位按视觉等效 px 换算）；独立控件按设计需要设置。
- **强调色前景配对**：所有强调色填充表面默认使用白色文字和图标（不随浅/深色切换反转）；仅当白色与最终合成表面对比度低于 `3:1` 时改用黑色前景，填充与前景成组维护并在浅/深/系统外观及交互态下验证。
