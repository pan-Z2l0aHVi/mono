# 文档与术语约束

- **Markdown 标题禁反引号**：`#`–`######` 各级标题禁止使用行内代码反引号，直接写自然语言或纯文本名称。
- **只陈述现状**：注释与文档散文只写当前行为与设计意图，不叙述被取代的旧实现、旧属性名或改动过程。
- **术语用代码英文原名**：文档、注释与示例中的组件/构件/概念术语使用代码英文标识（如 `web-ui-slider`、thumb、indicator、track），不自造或混用中文译名（如手柄、滑块、指示器）；中文只写行为、状态与解释，领域词遵从所属包 `AGENTS.md` 或 `docs/`。
