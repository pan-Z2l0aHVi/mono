`web-ui-drawer` now supports double-clicking the drag handle (`.wui-drawer-drag-zone` and `.wui-drawer-drag-edge`) when `fullable` and `draggable` are enabled to toggle between the viewport-filling full state and the default size, staying consistent with drag-to-full gestures, nested drawer stacking, and reduced-motion behavior.
