Internal change: no published package is affected. Root engineering config and the docs that describe it now say the same thing.

- `vite.config.ts`: dropped the `staged:` block. `.vite-hooks/pre-commit` runs only `pnpm task guard` since ADR-0014 retired the `vp staged` pipeline, so those four patterns had no caller left — and `scripts/task.test.mjs:15` asserts the hook must not run `vp staged`.
- `docs/agents/linting.md`, `docs/agents/build.md`, `docs/agents/worktrees.md`: removed the claims that the commit hook runs `vp check --fix`, `stylelint --fix` or `gofmt -w` on staged paths, and named the hook that remains: `pre-commit` runs `pnpm task guard`, `commit-msg` runs commitlint. Formatting is applied by `fix:code` and by `freeze`. `docs/adr/0001-ci-pipeline.md` and `docs/adr/0002-build-toolchain.md` state the retired claim in their own bodies, so each stale sentence keeps its original text plus a dated 修订 note, both files gained an `Amended by` header line pointing at ADR-0014 (the shape ADR-0011 uses), and `CONTEXT.md` annotates both index rows; un-annotated present-tense mentions now survive only in the dated ledgers under `docs/testing/batch-d-lists/`. `linting.md` also matches what the scripts actually do: `check:go` asserts `gofmt -l` before `go vet`, and `fix:go` runs `go vet` too.
- `pnpm-workspace.yaml`: removed `minimumReleaseAgeExclude: ['@shadcn/lint@0.1.1']`. Since v11 pnpm ships a built-in `minimumReleaseAge` of 1440 minutes, and that entry was the 24-hour pass that let a version published 2026-09-17 install on day one. An exclusion has no expiry — pnpm keeps honouring it until it is deleted (auto-cleanup needs `minimumReleaseAgeExcludePrune: true`, default false) — so while it changes no resolution result at today's threshold, leaving it behind means it silently re-gains teeth if the threshold is ever raised. Two claims from the review report were wrong and are corrected in `docs/agents/dependencies.md`: the repo does have a maturity gate in force (pnpm's default, not a setting we wrote), and pnpm 12 reads nothing but auth and registry from `.npmrc`, so `minimum-release-age=10080` in `apps/interweave/frontend/.npmrc` is dead config whose "honoured by pnpm" comment needs its own look. The doc now states the effective defaults, where a stricter gate would be written, and that an exclusion is temporary and must be deleted by hand; the same section also records where `@shadcn/lint` sits and what it costs.
- `cspell.json`: dropped `indep` and `bopan`. They were only there to spell `scripts/task.test.mjs` fixture ids, which now read `independent-reviewer-1` and `user-approver`; `check:cspell` never scans `.md`, so a doc wording can never need a dictionary entry. This reverses `.changeset/cspell-dict-indep-bopan-260918.md`, an 8-byte shell that recorded no reason for adding them.
- `CONTEXT.md`: the ADR-0001 index row routed readers to a sentence ADR-0014 retired, so it — and now the ADR-0002 row — carry the "已退役，需连读" annotation the 0011/0012 rows use.
