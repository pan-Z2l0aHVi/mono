Internal change: the Interweave settings dialog is no longer an empty-state placeholder. It gains three sections — General, Appearance, and Library — behind a segmented control. General carries a disabled MCP server switch marked as forthcoming. Appearance carries a three-state theme control (light, dark, follow system) and a six-swatch accent palette. Library stays a placeholder, matching the unimplemented Settings route.

Theme mode and accent are held in a new Pinia settings store and persisted through `@greypan/browser-kit`'s `local`, the same read/write path the web-ui demos use, keyed `theme-appearance` and `theme-accent`. Both values are read back through type guards, so a stale or hand-edited entry falls back to the default rather than reaching the inline style. `App.vue` binds the store to `web-ui-theme`, keeping the `appearance` attribute always present and overriding `--wui-color-accent` inline so one declaration covers the light, dark, and system branches. The accent foreground is white throughout, so every swatch clears WCAG AA 4.5:1 against it: green and orange are deepened to `#1d8348` and `#c64600` because Apple's `#30d158` and `#ff9f0a` reach only 2.02:1 and 2.06:1 on white, while the other four keep their Apple values at the same 3.4–3.7:1 tier web-ui's own accent already sits in. No new dependencies, and no published package version changes.
