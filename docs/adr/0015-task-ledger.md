# ADR-0015: Task 分级与台账复用

- **Date**: 2026-10-19
- **Status**: 已接受

## 背景

风险分级和本地 task 归属可跨项目复用；worktree、review、发布和授权要求则属于宿主仓库。

## 决策

`task-ledger` skill 承载分级和本地台账，不承载 review、CI 或发布结论。分级依据改动影响，避免依赖具体包名或固定目录清单；现行判据由 skill 维护。宿主仓库负责 worktree、review 和交付规则。

台账存放在系统临时目录，按 Git common directory 派生的仓库标识隔离。它是可丢失的工作记忆，记录归属、进度与引用，不是审计记录。PR、Git 历史和其他持久文档承载交付结论。

## 后果

- 其他仓库可以复用分级和记账，不必继承本仓的编排政策。
- 临时记录可能随清理或重启消失，恢复时必须核对实际 Git 状态和持久证据。
- 台账不会执行检查或 Git 写操作，其终态不表示 review、测试、CI、merge 或发布成功。
