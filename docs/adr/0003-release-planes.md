# ADR-0003: 发布平面

- **Date**: 2026-08-02
- **Status**: 已接受

## 背景

Changesets 生成共享的 Version PR，但 npm registry 发布与桌面端交付所需的权限、工作流和工具链不同，不能由同一条流水线串行承担。

## 决策

- registry 发布和桌面端交付是独立的发布平面：npm 包通过 Trusted Publishing 发布，Wails 安装程序通过 GitHub Release 发布，两者并行执行；每个平面拥有各自的工作流、权限、工具链和重试路径。
- Version PR 的合并是唯一的正式发布授权；手动运行仅可用于验证产物。

## 后果

- 发布状态以 Version PR 合并为唯一判据：手动触发的工作流即使产出可用制品，也只作为验证证据，不构成发布。
- 两个平面并行执行，可独立重试，互不阻塞。
