# ADR-0022: Layout 由应用控制移动端状态

- **Date**: 2026-11-08
- **Status**: 已接受
- **取代**: ADR-0011

## 背景

应用的响应式交互与布局需要共享移动端状态，同时各应用可能使用不同断点。

## 决策

`web-ui-layout` 的 `mobile` 是默认值为 `false` 的受控布尔 property，并反射到同名 attribute。组件不判断视口，也不派发 `mobile-change`。应用负责判断和更新状态，CSS 可使用 `web-ui-layout[mobile]` 选择布局子树。

## 后果

- 应用负责初始值、视口变化订阅与资源清理。
- 组件布局和应用状态由同一输入驱动；应用可独立选择断点。
- 属性选择器不覆盖 portal 到布局子树外的内容，此类内容需要独立样式策略。
