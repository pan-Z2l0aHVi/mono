# ADR-0029: Interweave Map 局部探索操作边界

- **Date**: 2026-08-16
- **Status**: 已接受

## 背景

Map 负责从 Resource 与语义标签的归属中派生资源关系地形图。若在 Map 中加入手工画布排版、拖拽连线、批量打标或直接编辑 Source，会把只读与轻量探索视图变成复杂的图形编辑器，增加状态同步负担并偏离“关系由标签派生且始终可解释”的核心。

## 决策

v1 的 Map 保持为探索和轻量就近纠正视图。聚焦某个语义标签展开后，支持的操作限定为：

1. 查看直接拥有该标签的 Resource 节点；
2. 查看这些 Resource 还拥有的其他语义标签，并支持逐层继续探索；
3. 点击 Resource 查看其详情、首选 Source 及其可用性状态；
4. 在选中的单个 Resource 上就近添加或移除标签（即增删 `Tagging`），并即时触发局部网络和关系的重算。

Map 严禁提供手工拖拽连线、自定义图布局持久化、批量打标签、在画布上直接增删/替换 Source 或复杂条件过滤。

## 后果

- Map 的后端只负责提供主题聚合与局部探索派生数据，不持久化节点坐标或手工连接。
- Map 中的唯一写操作完全复用 ADR-0028 规定的单 Resource 标签操作（`Tagging` 增删）。
- 前端 Map 视图定位为轻量交互探索层，不是图形设计器或通用知识图谱编辑器。
