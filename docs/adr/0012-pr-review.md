# ADR-0012: PR 独立审查与增量复审

- **Date**: 2026-10-18
- **Status**: 已接受

## 背景

本地 hook 能发现遗漏的检查，不能证明独立 review 已完成。将独立 review 放在 PR 阶段，允许实施者小步提交，并让 reviewer 检查完整变更及验证证据。

## 决策

T0/T1 的首次 PR review 由独立 reviewer 检查完整 PR diff、验收条件和相关证据，报告记录 base/head SHA、发现及未覆盖风险。task 台账、实施者自查与 CI 均不能替代 review。

已有有效完整审查后，后续轮次以已审查 head 为基准，只审查到新 head 的增量、前轮发现的修复及其受影响行为，并结合前轮结论更新整个 PR 的结论。记录各轮覆盖的 SHA 和未解决问题，避免重复审查未变的内容。增量不明、前轮证据不可用，或 base、历史与审查范围变化使旧结论不再可靠时，重新检查受影响范围；无法确定范围时重新完整审查。

本地政策检查只读且独立于 task 台账；PR CI 负责 changeset 和政策检查。远端规则集及 review 回写、merge 授权按现行仓库流程执行。

## 后果

- PR 结论必须覆盖当前 base/head；一次旧 head 的报告不能单独证明新 head 已通过 review。
- 增量复审减少重复工作，同时保留检查关联行为和重新扩大范围的责任。
- CI 只提供自动检查证据，不代表独立 review 或发布授权。
