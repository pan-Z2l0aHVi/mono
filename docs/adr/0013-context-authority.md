# ADR-0013: Context 语料权威与漂移检查

- **Date**: 2026-10-19
- **Status**: 已接受（2026-11-08 修订：只读报表与语料指纹已随 ADR-0022 一并删除，相关句子改为历史口径）

## 背景

Instruction 可能被客户端按层加载，也可能被检索系统按片段读取。文件存在或链接可解析，不代表检索内容仍是现行事实。

## 决策

每个主题只有一个权威来源；其他位置提供路由，不复制易变状态。非权威参考语料标明身份，授权和前置条件在检索片段中保持可理解。被取代的决策从现行语料移除，历史由 Git 保存。

`check-context` 检查路由、链接、授权指针、非权威标记和可客观判定的漂移。全仓已跟踪 Markdown 纳入链接检查，指令面另检查路由和互指。文档体量不设字符数门槛，也不以文风扫描代替语义 review。（引入时曾附「只读体量报表」，已随 ADR-0022 删除，不再是本决策的一部分。）

## 后果

- 权威归属和失效内容需要人工维护；机器检查只覆盖可判定的属性。
- （2026-11-08 起失效）曾以「语料指纹」反映内容集合及变化；该判据与观测出口已随 ADR-0022 删除，不再证明任何外部索引状态。
- 规则细节以 agent-context.md 和检查实现为准。
