## 强调色前景配对

本规则用于所有应用与 UI 组件中以强调色填充的主操作、选中项及其他强调色表面。macOS 的系统强调色体验是视觉参考；以下配对是明确的产品规则，不推断或承诺复刻系统内部算法。

- 默认使用白色文字和图标。浅色、深色或系统外观切换本身不应导致前景色反转。
- 仅当白色与最终呈现的强调色表面对比度低于 `3:1` 时，才改用黑色前景；半透明颜色按合成后的表面判断。
- 将强调色填充与其前景色作为一组维护。自定义强调色、交互状态或主题变化时，同步调整这组颜色，保持至少 `3:1` 对比度；否则调整填充色或呈现方式。
- 此规则只约束强调色填充表面上的文字和图标，不替代中性表面上的强调色文字、描边、焦点指示或语义色各自适用的对比度要求。`3:1` 是本配对规则的最低判据，不代表对所有字号和内容的无障碍要求均已满足。

验证时检查浅色、深色和系统外观，以及默认、悬停、按下和选中状态下的实际前景与填充配对。
